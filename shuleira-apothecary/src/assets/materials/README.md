# 素材画像の置き場所

作者から画像を受け取ったら、このフォルダに「素材ID.拡張子」で配置する
（拡張子は png/jpg/jpeg/webp のいずれでも自動的に読み込まれる）。
ファイルが無い素材は、代わりに分類別アイコン（自動生成SVG、色分け済み）を表示する。
つまり **22種すべて揃っていなくても崩れない**。1つ置けば1つだけ差し替わる。
コード側の対応表は `src/main.ts` の `import.meta.glob('./assets/materials/*...')`。

ファイル名は素材の日本語名ではなく **素材ID（M01〜M22）** で統一してほしい
（文字化け・大文字小文字違いの事故を避けるため）。どの絵か分かるよう、
下の表にファイル名・名前・分類・簡単な見た目メモを並べてある。

## 技術仕様
- 透過PNG推奨。器（瓶・壺・包み・欠片など）1点のみを中央に配置した構図。
- 正方形に近い比率（棚のマスが正円のバッジなので、中央に主題が来るように）。
- 512×512px 程度を目安（拡大縮小されるので極端に小さくなければ問題ない）。
- 文字・ロゴ・魔法陣などの装飾は入れない（世界観上、魔法的な図像は禁止 — decisions.md参照）。
- キャラクター立ち絵と同じ画風・トーンで統一されていると馴染む（必須ではない）。
